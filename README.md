🪾 Description

Furina is a multifunctional WhatsApp bot based on "baileys". This bot provides a variety of features to improve your WhatsApp experience.

---

☃️ Features

- Automatic responses
- Group management
- Interactive games
- Integration with external APIs

---

Basic Installation

<details>
<summary><strong>🦦 Cloud</strong> — Shell</summary>Install the required dependencies and start Furina from the project directory.

</details><details>
<summary><strong>🦦 Termux</strong> — Manually</summary>Install the required dependencies, clone the project, install the packages, and start Furina.

Keeping Furina Online

Furina can be managed using PM2 to keep the bot running and automatically restart it if the process stops.

---

If Furina Stops

If Furina stops after installation, Termux becomes inactive, your internet connection is lost, or you restart your phone, simply start Furina again from the project directory.

---

Getting a New Session

If you need to log in to Furina again, remove the existing Owner session and start the bot again to generate a new login session.
